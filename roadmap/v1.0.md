# 📍 FXAssistant v1.0 Roadmap

---

## ✅ Phase 1 – MVP Plugin (Weeks 1–2)
- Build AU plugin shell using JUCE
- Basic GUI: one knob (e.g., gain), empty preset loader
- Commit to GitHub with clean structure

## ⚙️ Phase 2 – FX Chain Recommender (Weeks 3–6)
- Add genre dropdown
- Hardcode 10 genre-based FX chain presets in JSON
- Create reference audio selector
- Display mapped plugin chain visually

## 🎹 Phase 3 – MIDI Humanizer + Session Tracker (Weeks 7–10)
- Implement velocity/timing modifier using groove templates
- Log plugin changes to session history
- Auto name channels based on reference/stems

## 📱 Phase 4 – Mobile Mix Sim + Cloud Sync (Weeks 11–14)
- Add phone speaker simulation (via filter curve)
- Django backend to sync user sessions + presets

## 🧪 Phase 5 – GUI Polish + Beta Launch (Weeks 15–17)
- Style full plugin UI
- Add feedback form + error logs
- Integrate Stripe + finalize licensing

---

## 💡 Stretch Features (v2+)
- TorchScript genre recognition from reference
- Cross-DAW sync and stem chat threads
- ML-driven FX chain optimization
